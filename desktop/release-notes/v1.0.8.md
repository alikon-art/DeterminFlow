DeterminFlow 1.0.8 改善 Windows 桌面更新、首次配置诊断和长期运行时的稳定性。

- Windows 桌面更新和官方 Plugin 下载改为 Gitee 优先；同版本且签名一致时，Gitee 下载失败会自动回退 GitHub，最终仍由 Tauri 公钥验签。
- Provider Base URL 会规范化 OpenAI 兼容接口路径，减少因遗漏或重复 `/v1` 导致的模型调用失败。
- 桌面端会直接显示 Backend 启动日志和 Provider 配置错误，不再把运行时故障表现为长期等待或空白界面。
- Windows Task 状态持久化遇到短暂文件占用时会有限重试，并清理遗留临时文件，降低终态写入失败概率。
- 终态 Workflow Session 默认只保留最近 1000 条可安全删除的历史记录；运行中、可恢复和交互 Main Session 不参与清理，Task、Workspace、Job、SSE、Token、计费和 Plugin 数据不会被删除。

本版本不迁移或覆盖已有 Workflow、Task、Workspace、Plugin、模型配置和用户数据。服务版入口继续使用仓库根目录的 `python run.py`，不会初始化桌面更新功能。

已知限制：安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
